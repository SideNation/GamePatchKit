## 개요
이 PRD가 다루는 대상이 무엇이고 왜 필요한지 1~3문장.

## 개발 v1

### 트리거
- 사용자가 어떤 어구를 썼을 때 이 기능/스킬/에이전트가 동작하는지
- 예: "개발 문서 작성", "prd 작성"

### 범위
- 이 PRD가 포함하는 것
- 명시적으로 포함하지 않는 것 (선택)

### 산출물
- 만들어질 파일 경로·형식
- 예: `packages/skills/<name>/SKILL.md`

### 동작 규칙
- 핵심 동작 흐름을 번호 목록으로
1. ...
2. ...

### 제약 / 비고 (선택)
