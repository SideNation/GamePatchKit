# <기능명>

## 개요
이 기능이 무엇이고 언제 쓰는지 1~3문장.

## 사용법
- 진입점(클래스/메서드/씬 이름)과 호출 예시 코드
- 주요 파라미터 설명 (비자명한 것만 — 타입 나열 금지)
- 콜백/이벤트가 있으면 시그니처 명시

```csharp
// 실제 컴파일되는 호출 예시
```

## 흐름
필요 시 상태/단계 흐름을 번호 목록 또는 다이어그램으로.

1. ...
2. ...

## 에러 처리
주요 `statusCode` / `errorCode`와 대응 동작.

| 코드 | 의미 | 권장 처리 |
|------|------|-----------|
| `EXAMPLE_CODE` | 의미 설명 | 클라이언트 처리 방식 |
