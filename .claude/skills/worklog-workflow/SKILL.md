# 작업 일지

사용자 요청과 수행한 작업을 `docs/worklog/YYYY-MM.md`에 기록한다.

## 절차

1. 오늘 날짜로 `docs/worklog/YYYY-MM.md` 경로를 정한다.
2. 파일이 없으면 `# YYYY-MM 작업 일지` 제목으로 만든다.
3. 오늘 날짜의 `## YYYY-MM-DD` 섹션이 없으면 파일 맨 아래에 추가한다.
4. 사용자 요청 하나당 항목 하나를 오늘 날짜 섹션 아래에 추가한다.
5. 같은 요청을 이미 기록했으면 중복해서 추가하지 않는다.
6. 과거 항목은 수정하지 않는다.

## 형식

```markdown
## YYYY-MM-DD

### <사용자 요청 한 줄 요약>

- 작업: <수행한 내용과 결과>
- 다음: <미완료 작업이 있을 때만>
```

## 원칙

- 요청은 한 문장, 작업은 1~3개 항목으로 적는다.
- 검증 결과가 중요하면 작업 항목에 포함한다.
- `다음`은 미완료 작업이 있을 때만 적는다.
- 월별 파일의 아래쪽에 새 기록을 추가한다.
- 작업일지는 `AGENTS.md`나 `CLAUDE.md`에 적지 않는다.
