# 작업 일지 (Worklog)

날짜별 작업 진행·인수인계 메모를 `docs/worklog/` 아래 **월별 파일**(`YYYY-MM.md`)에 남긴다. 서로 다른 컴퓨터·세션의 AI가 "어제 뭘 했는지" 이어받게 해주는 공유 기억이다.

- **한 달 = 한 파일.** 하루가 아니라 달 단위로 파일을 만든다.
- 컨텍스트(아키텍처·규칙·사용자 정보)는 `AGENTS.md`, 날짜별 진행/인수인계는 이 스킬로 역할을 나눈다.
- 인덱스: [docs/worklog/README.md](../../../Docs/worklog/README.md)

## When to invoke

| 상황                                 | 작업                                     |
| ------------------------------------ | ---------------------------------------- |
| 작업이 일정 부분 완료됨              | 그 달 파일에 오늘 날짜 섹션 추가/갱신    |
| 세션 종료·창 전환 전 인수인계       | 오늘 섹션에 "다음 창에서 이어갈 일" 기록 |
| 버그 수정·기능 구현 마무리          | 오늘 섹션에 수정/구현 항목 추가          |
| 단순 질문·조회, 동작 변화 없는 확인 | 기록 불필요 — 남기지 않는다             |

## Procedure

1. **월 파일 경로 결정** — 오늘 날짜로 `docs/worklog/YYYY-MM.md`를 정한다. (예: 2026-07 → `docs/worklog/2026-07.md`)
2. **파일이 있으면 읽고 이어 쓰기** — 그 달 파일이 있으면 읽는다. 오늘 날짜(`## 📋 YYYY-MM-DD`) 섹션이 이미 있으면 그 안에 항목을 추가한다.
3. **없으면 새로 만들기** — 그 달 첫 로그면 `# YYYY-MM 작업 일지` 제목으로 파일을 만든다.
4. **오늘 섹션 추가** — 오늘 첫 기록이면 파일 **맨 아래**(최신이 아래로 append)에 `## 📋 YYYY-MM-DD 작업 일지` 섹션을 붙인다. 하루에 여러 세션이면 같은 섹션에 이어 쓰거나 `### 오후` 같은 소제목을 쓴다.
5. **README 인덱스 갱신** — 새 월 파일을 만들었거나 새 날짜가 목록에 없으면 [README.md](../../../Docs/worklog/README.md)의 "목록" 을 갱신한다.
6. **AGENTS.md는 건드리지 않는다** — 실제로 컨텍스트가 바뀐 경우(새 아키텍처·새 규칙·브랜치 변경 등)만 AGENTS.md를 따로 갱신한다.

## 엔트리 형식

한 날짜 섹션은 아래 뼈대를 따르되 **필요한 소제목만** 쓴다.

```markdown
## 📋 2026-07-04 작업 일지 (작성자 → 다음 세션 전달용)

### 오늘 한 것
- 한 줄 요약 1
- 한 줄 요약 2

### ✅ 수정/구현: <제목>
**증상/배경:** ...
**원인:** ...
**수정:** ...
**파일:** `path/to/file.cs`

### 🔴 미완료 / 다음 창에서 이어갈 일
- ...

### 🗒️ 메모
- ...
```

## Writing principles

1. **다음 세션이 이어받게** 쓴다 — 무엇을, 왜, 어디(파일·브랜치)까지 했는지. 인수인계면 "다음에 할 일"을 반드시 남긴다.
2. **append-only** — 최신 날짜가 파일 아래로 쌓인다. 과거 날짜 항목은 사후 수정하지 않는다.
3. **한국어로 작성**, 코드·경로·식별자·에러 코드는 영어 그대로.
4. 커밋·PR 번호는 git이 하므로 본문에 굳이 적지 않는다. 브랜치명은 인수인계에 필요할 때만 적는다.
5. 한 달 = 한 파일. 월이 바뀌면 자동으로 새 파일이 된다.

## Anti-patterns

- AGENTS.md·CLAUDE.md에 작업 일지를 쌓는다. → 반드시 `Docs/worklog/`에.
- 날짜마다 새 파일(`YYYY-MM-DD.md`)을 만든다. → 월별 파일에 `##` 섹션으로.
- 과거 날짜 항목을 사후 편집한다.
- 조회·단순 질문·동작 변화 없는 확인까지 일지에 남긴다.
